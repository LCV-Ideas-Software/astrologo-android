# Security Policy

## Supported state

Only the current `main` branch is maintained. The repository presently holds
documentation, workflow configuration, a sanitized static page, and an inert
Code Quality probe. It does not contain an Android application, production
runtime, signing material, account integration, billing implementation, or
published release.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting route:

- https://github.com/LCV-Ideas-Software/astrologo-android/security/advisories/new

If that route is unavailable, contact `lcv@lcv.dev` privately.

Do not disclose a suspected vulnerability, credential, signing artifact,
personal datum, payment issue, supply-chain weakness, deployment
misconfiguration, or unpublished operational detail in a public Issue,
Discussion, pull request, commit, or Pages content.

Include the affected revision, a concise impact description, reproducible
steps that do not expose secrets, and any safe mitigation already tested.
Never send live credentials. Revoke or rotate exposed credentials through
their owning system and report only non-secret metadata.
